# email-assets

Public static images hotlinked from Swift Solar email signatures, served via GitHub Pages.

**Do not rename, move, or delete files.** Signatures already sent reference these URLs; removing a file breaks the image in old emails.

- Add new assets under `signatures/<year>-<event>/` with descriptive, dated filenames.
- Everything in this repo is public. Never commit anything sensitive.
